## 1. 시간복잡도가 필요한 이유

코드가 "정답을 내는가"뿐 아니라, 데이터가 커져도 감당 가능한가를 판단하는 기준

> 입력 크기 n이 커질 때 연산 횟수가 어떤 비율로 증가하는 가

## 2. 가장 중요한 복잡도

O(1): 입력 크기와 무관
`list[i]` 같은 연산

O(n): 입력 크기만큼 확인
`for` 같은 연산 (1회 반복)

O(n^2): 이중 반복

O(log n): 범위를 절반씩 제거
`이진 탐색` 같은 알고리즘

O(nlog n): 효율적인 정렬 알고리즘에서 자주 나타남

맹목적으로 속도만 높이는 것은 좋지 않음
O(n^2)도 n <= 100 이라면 문제없는 것 처럼.

## 3. Big-O에서는 작은 항을 버린다

``` python
for number in numbers:
    print(number)

for number in numbers:
    print(number * 2)
```
n + n = 2n
But. 시간복잡도는 O(n)
