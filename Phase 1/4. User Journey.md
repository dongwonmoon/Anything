## 한 줄 정의

> **사용자가 목표를 달성하기까지 실제로 거치는 흐름을 시간 순서대로 따라가 보는 것**

어떤 기능은 개발자 입장에서 보면, **"기능 그 자체"** 이지만,
사용자 입장에서 보면, **"내가 원래 하려던 일을 하기 위해 통과할 관문"** 임.

---

## 왜 중요할까?

"엑셀 다운로드 버튼"을 만들었다 치자.
기능만 보면 만듦으로써 개선이 끝난 것 같지만,
Journey를 보면 문제가 보인다.
Journey:
> 1. 관리자 페이지에 로그인한다.
> 2. 매출 메뉴로 이동한다.
> 3. 기간을 지난달로 설정한다.
> 4. 필요한 필터를 선택한다.
> 5. 엑셀 다운로드 버튼을 누른다.
> 6. 파일을 연다.
> 7. 컬럼을 정리한다.
> 8. 합계와 그래프를 만든다.
> 9. 보고서 양식에 붙여넣는다.
> 10. 상사나 회계 담당자에게 전달한다.

생길 수 있는 문제점:
> 기간 필터가 없으면 사용자가 엑셀에서 직접 지워야 한다.
> 파일명이 이상하면 나중에 찾기 어렵다.
> 컬럼명이 내부 용어라서 보고서에 바로 쓰기 어렵다.
> 개인정보가 그대로 들어가면 공유하기 어렵다.
> 다운로드 시간이 너무 오래 걸리면 사용자가 실패한 줄 안다.

더 중요한 철학은, **기능 하나만 보지 말고, 사용자가 목표를 끝내기까지의 전체 흐름을 봐라.**

````
| 2 |  |  |  |  |

````

## AI에게 시킬 프롬프트

```text
이 기능을 바로 구현하지 말고,
사용자 여정(User Journey) 관점에서 분석해줘.

다음 항목으로 정리해줘.

1. 사용자의 최종 목표
2. 이 흐름이 시작되는 상황
3. 사용자가 거치는 단계
4. 각 단계에서 사용자의 기대
5. 각 단계에서 시스템이 보여줘야 할 반응
6. 사용자가 헷갈릴 수 있는 지점
7. 실패하거나 이탈할 수 있는 지점
8. 회복 방법
9. 가장 먼저 개선해야 할 단계
10. MVP에서 반드시 포함해야 할 흐름
```

## 간단한 예시

#### 예시 1. 비밀번호 찾기 기능
기능 중심으로 보면,
**이메일 입력 -> 재설정 링크 발송 -> 비밀번호 변경**

User Journey로 보면,

| 단계  | 사용자 행동     | 기대               | 불편/위험                  |
| --- | ---------- | ---------------- | ---------------------- |
| 1   | 로그인 실패     | 왜 실패했는지 알고 싶다    | 이메일 오류인지 비밀번호 오류인지 헷갈림 |
| 2   | 비밀번호 찾기 클릭 | 바로 찾기 흐름으로 가고 싶다 | 버튼이 눈에 안 띔             |
| 3   | 이메일 입력     | 내 계정으로 메일이 오길 기대 | 가입한 이메일을 기억 못 함        |
| 4   | 메일함 확인     | 메일이 빨리 오길 기대     | 스팸함에 들어감               |
| 5   | 링크 클릭      | 안전하게 변경되길 기대     | 링크 만료/오류 가능            |
| 6   | 새 비밀번호 입력  | 조건을 쉽게 이해하고 싶다   | 조건이 뒤늦게 표시됨            |
| 7   | 로그인 재시도    | 바로 성공하길 기대       | 변경 후 자동 로그인 여부 헷갈림     |

#### 예시 2. 회원가입
회원가입 기능의 확장:
```text
1. 사용자가 서비스 필요성을 느낀다.
2. 서비스에 들어온다.
3. 가입이 필요한 이유를 확인한다.
4. 회원가입 버튼을 찾는다.
5. 가입 방식 선택 화면을 본다.
6. 이메일 또는 소셜 로그인 중 선택한다.
7. 이메일을 입력한다.
8. 이메일 중복 또는 형식을 확인한다.
9. 비밀번호를 입력한다.
10. 비밀번호 조건을 확인한다.
11. 필요한 개인정보를 입력한다.
12. 약관을 확인하고 동의한다.
13. 이메일 인증을 진행한다.
14. 가입 완료 메시지를 확인한다.
15. 로그인 상태로 전환된다.
16. 가입 후 첫 행동을 한다.
```

중요한 건 마지막인데,
**첫 행동**은 어디서 왔는가?: 서비스의 필요성을 느끼고 기대한 행위를 하려 할 때.

예를 들어, 사용자가 게시글을 쓰려고 가입했다면,
가입 후 게시글 작성 화면으로 돌아가야 자연스러움. (게시글 버튼을 누르고 가입 화면으로 갔을 때!)
