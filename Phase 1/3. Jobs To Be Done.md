## 한 줄 정의

> **사용자가 제품이나 기능을 쓰는 이유를 "기능"이 아니라 "달성하려는 일"로 보는 관점**

[상황]에서, 나는 [동기/목표]를 위해, [기대 결과]를 얻고 싶다.
라고 작성하면 좋을 듯.

---

## AI에게 시킬 프롬프트

```text
사용자가 “OO 기능이 필요하다”고 요청했다.

바로 기능을 설계하지 말고,
이 요청에서, 사용자가 정말 원하는 작업(Job)을 분석해줘.

[상황]에서, 사용자는 [동기/목표]를 위해, [기대 결과]를 얻고 싶다.
로 정리해줘.

이후 각 기대 결과별 필요한 기능을 제시해줘.
```

---

## 간단한 예시

사용자 요청:

> 엑셀 다운로드 기능을 만들어줘.

그냥 엑셀 다운로드 기능을 만들어 줄 수도 있지만,

> 보고서를 제출하고 싶다
> 매출을 분석하고 싶다
> 증빙 자료로 남기고 싶다
> 공유하고 싶다
> 외부 시스템에서 후처리하고 싶다
> 세금 신고를 하고 싶다

등으로 사용자가 진짜 원하는 목적이 무엇인지 분석할 수 있고,
사용자가 진짜 원하는 목적에 따라 필요한 기능도 달라질 수 있다.

| 목적           | 필요한 기능                      |
| ------------ | --------------------------- |
| 보고서를 제출하고 싶다 | 보기 좋은 형식, 제목, 기간, 합계        |
| 세금 신고        | 정확한 날짜, 금액, 사업자 정보, 원본성     |
| 데이터 분석       | 원시 데이터, 필터 조건, 열 선택, CSV 지원 |
| 공유           | 읽기 쉬운 컬럼 명, 개인정보 마스킹        |
| 보관           | 파일명 규칙, 다운로드 이력             |
| 외부 시스템 업로드   | 정해진 컬럼 순서, 특정 포맷            |

이러면, 각 필요한 기능을 포함한 엑셀 시트를 배포할 수 있겠다.
