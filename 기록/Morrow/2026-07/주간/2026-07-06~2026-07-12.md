## 07.06
- 달력 기능 개발 
	- 기록 탭에서 달력으로 진입하는 UI 추가
	- 월별 기록 날짜 표시, 날짜 선택, 선택한 날짜의 기록 목록 표시
	- 달력은 별도 탭이 아니라 기록 탭의 보조 진입점으로 둠
		- 이유: 아직 핵심 기능은 "기록을 남기고 다시 보는 것"이고, 달력은 그중 하나의 보기 방식에 가까움
		- 검색/기록 목록/달력을 모두 크게 밀면 기록 탭이 무거워질 수 있음
	- 날짜 선택 터치 영역 확대
		- 원형 선택 표시만 누르게 두면 실사용에서 클릭이 답답함
		- 표시 UI는 유지하되, 실제 터치 영역은 날짜 셀 전체로 넓힘

- 모바일 viewport / layout 안정화 [[#Remind|↑ Remind]]^layout-problem
	- 기록 작성/수정 화면의 save dock이 safe area를 존중하도록 수정
	- 작성 화면의 반응형 layout 문제는 바로 뜯어고치지 않고 TECH_DEBT에 기록
		- 이유: 작은 padding 조정으로 해결하려 하면 기기별/키보드/SaveDock/긴 메모 케이스에서 다시 깨질 수 있음
		- 나중에 화면 layout system 자체를 정리할 때 다루는 편이 안전하다고 판단
		- 매직넘버, 상수 등을 최대한 제거하는 방향으로 진행? AI와 함께 어떻게 진행하는게 더 현업에서 주로하는 방식인지 물어보는 게 옳을 듯함.

- 기록 카드 / 홈 polish
	- 홈 최근 기록 rail 끝부분에 불필요한 trailing gap 제거
	- 사진 없는 기록 카드에서 책이 연결되어 있으면 책 표지를 fallback으로 사용
		- 이유: 기록 카드의 빈 이미지보다 연결된 책 표지가 더 정보성이 높고, "책과 연결된 기록"이라는 맥락이 잘 드러남

- 릴리즈 준비
	- Android versionCode 업데이트

## 07.07
- 기록 찾기 UI 단순화
	- 검색 shell에서 불필요한 "기록 찾기" 텍스트 제거
	- 이유: 검색 아이콘/입력 상태만으로 기능을 알 수 있고, 텍스트가 오히려 화면을 무겁게 만듦

- 나의 서재 MVP 개발
	- 기록에 연결된 책들을 snapshot 기반으로 grouping해서 "나의 서재" 화면 추가
	- 책 카드 클릭 시 해당 책과 연결된 기록만 모아보는 상세 화면 추가
	- book table 분리는 하지 않음
		- 이유: 아직 "책 자체"를 관리하는 앱이 아니라, 기록에 붙은 책 snapshot을 다시 보는 수준이면 충분함
		- books table을 만들면 migration, backfill, 같은 책 판별 규칙, snapshot vs 최신 책 정보 정책이 필요해짐
		- 따라서 지금은 snapshot 기반 grouping으로 시작하고, 나중에 책장/평점/읽는 중/책별 통계가 핵심이 되면 분리 재검토

- 책 표지 품질 개선
	- Aladin 검색 요청에 `Cover=Big` 추가
	- 이유: 나의 서재처럼 표지가 크게 보이는 UI에서는 기존 표지 해상도가 낮게 체감됨
	- 단, Aladin이 실제로 내려주는 URL은 여전히 provider 정책에 따름

- 나의 서재 / 책별 기록 화면 polish
	- 책별 기록 상세 화면도 내용이 넘칠 때만 스크롤되도록 viewport 정책 맞춤
	- 이유: BottomNav 위에서 컨텐츠가 자연스럽게 끝나야 하고, 짧은 화면에서 불필요한 스크롤/bounce가 생기면 완성도가 떨어져 보임

- 내부 화면 header 공통화
	- 기록 달력, 나의 서재, 책 선택, 기록 상세, 기록 작성/수정의 뒤로가기/제목 헤더를 `ScreenHeader`로 통일
	- 기록 상세는 본문 maxWidth 안에 header가 갇혀 버튼이 안쪽으로 모이는 문제가 있었음
		- header는 화면 폭 기준으로 배치
		- 사진/본문/책/삭제 영역은 기존 maxWidth 유지
	- 이유: 같은 내부 화면인데 뒤로가기 크기/위치/제목 스타일이 달라 보이면 앱 전체 완성도가 떨어짐
