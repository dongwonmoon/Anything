## 한 줄 정의

> **서비스가 장기적으로 잘 되고 있는지를 보여주는 가장 핵심적인 지표**

Success Metric은 보통 **특정 기능이나 문제 해결의 성공 기준**
North Star Metric은 **이 서비스 전체가 사용자에게 핵심 가치를 잘 제공하고 있는가?**

|구분|Success Metric|North Star Metric|
|---|---|---|
|범위|특정 기능, 특정 개선|서비스 전체|
|시간|단기/중기|장기|
|질문|이 기능이 성공했나?|이 서비스가 잘 가고 있나?|
|예시|검색 성공률, 가입 완료율|주간 활성 사용자 수, 완료된 거래 수|
|역할|개선 결과 판단|제품 방향 판단

---

## 왜 중요할까?

이름인 North Star에서 유추할 수 있듯이,
우리가 무엇을 목표로 보고 걸어나가고 있는지, 계속해서 확인시켜주고 각인시켜주는 역할인 듯하다.

---

## 좋은 North Star Metric의 조건

```
1. 사용자가 실제 가치를 얻는 행동과 연결된다.
2. 서비스의 장기 성장과 연결된다.
3. 너무 허상 지표가 아니다.
4. 팀이 방향을 잡는 데 도움이 된다.
5. 단순히 클릭이나 방문보다 결과에 가깝다.
```

예를 들어:

| 서비스     | 약한 지표    | 더 좋은 North Star Metric 후보 |
| ------- | -------- | ------------------------- |
| 쇼핑몰     | 방문자 수    | 구매 완료 수, 재구매 고객 수         |
| 예약 서비스  | 가입자 수    | 완료된 예약 수                  |
| 학습 앱    | 앱 실행 수   | 완료한 학습 세션 수               |
| 커뮤니티    | 게시글 조회수  | 의미 있는 댓글/답변이 달린 게시글 수     |
| 회계 SaaS | 로그인 수    | 월간 처리된 정산 건수              |
| 협업 도구   | 생성된 문서 수 | 2명 이상이 편집한 활성 문서 수        |

## 주의할 점 1

``` text
회원가입 수
다운로드 수
페이지 뷰
방문자 수
앱 설치 수
버튼 클릭 수
```
겉보기에는 좋아 보이지만, 핵심 가치를 관통하는 지표는 아닐 수 있다.
**무조건 나쁘진 않음**. 그러나, 더 중요한 지표가 존재할 수 있다.

## 주의할 점 2

North Star Metric은 중요하지만, 하나만 보면 위험하다.
예를 들어, 배달 앱이 "완료된 주문 수"만 보면 어떻게 되겠는지?

주문 수를 늘리기 위해:
> 배달원을 무리하게 배정
> 음식 품질 저하 (단기적)
> 가게 부담 증가
> 환불 증가

같은 문제가 생길 수 있다.
(주문 수는 일시적으로 늘어날 수 있지만, 장기적으로 보면 위험하다는 것이다.)

따라서, North Star Metric에는 보조 지표와 방어 지표가 필요함.
예:
```
North Star Metric:
- 완료된 주문 수
  
방어 지표:
- 환불율
- 취소율
- 평균 배달 시간
- 고객 불만률
- 라이더 과부하
```

## AI에게 시킬 프롬프트

```
이 서비스의 North Star Metric 후보를 제안해줘.

단순 방문자 수나 가입자 수 같은 허상 지표가 아니라,
사용자가 실제 가치를 얻는 행동과 연결된 지표를 찾아줘.

다음 항목으로 정리해줘.

1. 서비스의 핵심 가치
2. 주요 사용자
3. 사용자가 달성하려는 Job
4. North Star Metric 후보 5개
5. 각 후보의 장점
6. 각 후보의 위험한 해석
7. 보조 지표
8. 부작용을 감시할 방어 지표
9. 가장 추천하는 지표와 이유
```

## 간단한 예시

#### 중고 거래 앱

서비스의 핵심 가치는:
> 사람들이 물건을 사고팔 수 있게 하는 것

Then. North Star Metric은 단순 가입자 수 등이 아니라,
**완료된 거래 수**가 적합할 수 있다.

#### 배달 앱

핵심 가치는:
> 사용자가 원하는 음식을 주문해서 받는 것

Then. North Star Metric의 후보는:
**완료된 주문 수**일 수 있다.
